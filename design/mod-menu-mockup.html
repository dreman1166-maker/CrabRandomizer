This is a mockup, not the mod

UE4SS v3.0.1 gives Lua no drawing API at all, so the mod physically cannot paint this over the game. Everything here is real behaviour that already works — just reached today through randomizeset, the numpad keys and !rand chat commands instead of a panel.

To make it real: a UMG widget

Build this layout in Unreal Editor 4.27 with the Crab Champions modkit, cook it to a .pak, and the Lua side constructs it and calls AddToViewport. I can write all of that Lua — the editor half needs you, since I can't author assets.

The C++ / ImGui route is blocked

It would render in UE4SS's separate debug window, not over the game — and it can't be compiled anyway: RE-UE4SS's UEPseudo submodule 404s, so nobody can build the source tree right now.
