What changed from v1

v1 showed only settings, so mirror and independent looked identical on screen. Now the loadouts are the centrepiece and the mode is something you watch happen. That's the fix a design pass should find.

Still a mockup

UE4SS v3.0.1 gives Lua no drawing API. Every behaviour here is real and works today — via randomizeset, the numpad keys and !rand chat. Only the panel is imaginary.

To build it for real

UMG widget in Unreal Editor 4.27 + the Crab Champions modkit, cooked to a .pak. I write the Lua that constructs it and binds the buttons; the editor half needs you.

C++ / ImGui is blocked

Renders in UE4SS's separate debug window, not over the game — and can't compile anyway while RE-UE4SS's UEPseudo submodule 404s.
